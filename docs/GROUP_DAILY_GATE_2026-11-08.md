# Дневной фильтр 16 групп: диагностика и одна проба

Статус: **локальное исследование, не изменение живого бота**. Период расчёта — 1 июля — 7 ноября 2026, 27 заранее выбранных монет, 1Д-контекст и 4Ч-вход. Это уже просмотренная история, не независимое подтверждение. Исходный профиль, группы и сопровождение сделок не менялись. Код проверки: `evaluation/group_daily_gate_trial.py`.

## Что отсекает дневной фильтр

В сетке решений было 36 168 отказов с меткой `daily_regime`. Это **не 36 168 разных сделок**: один дневной режим оценивается шесть раз за сутки на 4Ч-границах и отдельно для лонга и шорта.

| Первое не пройденное условие | 4Ч-решений | Смысл |
| --- | ---: | --- |
| Собственный 1Д-режим монеты | 32 854 | Нет нужного подтверждённого тренда или нейтрального диапазона |
| Контекст BTC | 3 314 | Режим BTC не разрешает направление по правилу группы |
| **Всего** | **36 168** | |

Внутри первого пункта 17 360 отказов — собственный дневной режим ещё не подтверждён, а 964 — направленный день есть, но система ждёт второго последовательного дня. Следовательно, простое снятие требования второго дня затронуло бы только часть отказов. Среди BTC-причин: нейтральный режим — 1 482 решения, переходный — 1 716, остальные направления — 116. Для каждого случая отдельно сохранены и количество уникальных связок «монета — сторона — день», чтобы не путать повторные 4Ч-проверки с независимыми эпизодами.

## Единственный заранее заданный вариант

Для групп, где сейчас требуется совпадение с BTC, исследовательский вариант разрешает **собственный подтверждённый 1Д-тренд монеты при нейтральном BTC**. BTC в противоположном или переходном режиме по-прежнему блокирует идею. Относительная сила, дополнительный ETH-бенчмарк для подходящих активов, лимит дневной волатильности, 4Ч-геометрия и остальные групповые условия не ослаблены. BTC, ETH, приватные монеты и RWA этим вариантом не меняются.

Из 1 482 повторных 4Ч-решений с нейтральным BTC 1 400 не прошли затем подтверждение цены на 4Ч. Итог: четыре новых **технических кандидата** — AAVE long (2), SUI short (1), WLD short (1). Консервативно отдельными остаются три. Вместе с исходными правилами число технических кандидатов меняется с 50 до 54, отдельных идей — с 30 до 33 за 17 полных недель. До ориентира 20 сетапов в неделю это не доводит.

Это проверка **частоты, а не качества сделки**: входы, стопы, прибыль, funding и историческая допустимость этих четырёх идей здесь не оценивались. Текущие паспорта и параметры контрактов нельзя задним числом считать подтверждёнными на каждую историческую дату. У независимого периода ещё нет результата; замороженный сбор данных и его профиль не затрагивались. Автоматического переноса этого варианта в сканер нет.

## Решение по следующему этапу

Не ослаблять подряд EMA, ADX и 4Ч-подтверждение по уже просмотренным датам. Вместо этого сначала проверить, почему именно 1Д-состояние монеты часто остаётся неподтверждённым, и заранее описать **одну** альтернативу для «зарождающегося тренда» с явной пометкой меньшей зрелости сетапа. Сравнивать её с действующим режимом только на новых данных и после расходов. Если данных по группе или направлению мало, результат так и обозначать. В живой бот переносить лишь после отдельного решения, без изменения уже открытых сделок.

Подход «1Д для контекста, меньший таймфрейм для входа» описан в [учебном материале CME](https://www.cmegroup.com/education/courses/using-the-trading-simulator/trading-sim-in-30-seconds-chart-time-frames), а [BIS показывает](https://www.bis.org/publ/bisbull56.pdf), что совместное движение криптоактивов заметно, но не одинаково для всех пар. Эти источники объясняют постановку проверки, **не доказывают** доходность конкретных порогов бота.

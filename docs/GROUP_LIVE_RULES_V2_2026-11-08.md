# Групповые стратегии в рабочем сканере — v2

С 8 ноября 2026 года сканер и `/plan` используют один и тот же маршрут для всех 16 групп. Сначала действует прежний групповой вход из `evaluation/sector_entries.v2.json`; если он не нашёл сетап, проверяется дополнительная форма входа из `trading/group_live_rules.v2.json`. Успешный прежний сигнал не заменяется новым, а открытые сделки сохраняют свою записанную версию и старое сопровождение.

«Флаг» означает 4–8 закрытых 4Ч-свечей сжатия и подтверждённый выход по дневному тренду; «пробой с подтверждением» требует отдельной следующей закрытой 4Ч-свечи; «структурный диапазон» определяется повторными касаниями границ. Геометрия уровней остаётся фиксированной из подготовленных карточек, без оптимизации по уже просмотренному периоду. Для токенизированного золота прежнее правило работает, но новый вход не включён до независимой проверки связи цены контракта с базовым активом.

Все варианты используют только закрытые 1Д/4Ч-свечи. Перед отправкой бот ещё раз проверяет действующий контракт, текущие оборот, стакан, спред, влияние объёма на цену и то, что точка входа не была пройдена. Действуют максимум 8 часов ожидания входа, максимум 72–96 часов удержания и запрет второй незавершённой сделки по монете. Ни один из этих фильтров не доказывает доходность; 20 сетапов в неделю остаются ориентиром, а не обещанием.

Источники формы сигналов: [CME: тренд и продолжение](https://www.cmegroup.com/education/courses/technical-analysis/trend-and-continuation-patterns), [CME: поддержка и сопротивление](https://www.cmegroup.com/education/courses/trading-and-analysis/support-and-resistance.hideSubnav.educationIframe.html?hideAddThisExt=y&hideFooter=y&hideHeader=y). Они объясняют тип технического входа, но не подтверждают прибыльность этих конкретных правил. Позднейшие изменения порогов должны получать новую версию стратегии; результаты сравниваются отдельно по группе и направлению после расходов.
